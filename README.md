# Явь Щукинская

Лендинг кластера арт-деревень «Щукинская Явь» — проекта возрождения деревни Щукино в Псковской области. Одностраничный статический сайт: ретрит-туры, афиша событий, арт-резиденция, галерея, карта проезда и контакты.

Проект не использует сборщиков, фреймворков и пакетных менеджеров — это чистые HTML, CSS и JavaScript.

## Стек

- **HTML5** — семантическая разметка, один файл `index.html`.
- **CSS3** — кастомные свойства, Grid, Flexbox, `scroll-snap`, медиазапросы.
- **Vanilla JavaScript (ES2015+)** — без зависимостей.
- **Canvas 2D API** — интерактивная анимация частиц в hero-блоке.
- **IntersectionObserver** — запуск анимации звёзд только в зоне видимости.
- **Яндекс.Карты** — встроенная карта проезда через конструктор.

Шрифты подключаются с CDN:

- [Bergamasco](https://fonts.cdnfonts.com/css/bergamasco) — акцидентный шрифт заголовков;
- [Golos Text](https://fonts.google.com/specimen/Golos+Text) — основной текстовый шрифт;
- [Roboto Condensed](https://fonts.google.com/specimen/Roboto+Condensed) — подписи и служебный текст.

## JavaScript

`js/main.js` подключается в конце `<body>` и состоит из трёх частей.

### Карусель галереи

Кнопки `[data-gallery-prev]` и `[data-gallery-next]` прокручивают трек на ширину одного слайда. Сама прокрутка нативная: CSS задаёт `overflow-x: auto` и `scroll-snap-type: x mandatory`, JavaScript лишь вызывает `scrollBy` с плавной анимацией.

### Бургер-меню

На экранах до 900px переключает классы `is-open` у навигаций и `menu-open` у `body` (последний блокирует скролл страницы), а также состояние `aria-expanded`.

### Вращение звёзд

Все элементы с классом `.js-star` получают класс `is-spinning`, пока находятся в области видимости (порог 15%). CSS крутит их на 360° за 48 секунд. При `prefers-reduced-motion: reduce` анимация не запускается.

### Анимация частиц в hero

Текст «ЯВЬ ЩУКИНСКАЯ / ваше место проявления / КЛАСТЕР АРТ-ДЕРЕВЕНЬ» растеризуется на скрытом canvas, затем сканируется по пикселям: там, где есть непрозрачные точки, создаются частицы. В основном цикле они отталкиваются от курсора и пружиной возвращаются на исходные позиции.

Настройки находятся в объекте `settings` в начале `initHeroParticles()`:

| Параметр | Значение | Назначение |
|---|---|---|
| `gap` | `1.5` | Шаг сканирования в CSS-пикселях: меньше — плотнее и глаже контур, но больше частиц |
| `alphaThreshold` | `100` | Минимальная альфа пикселя, при которой создаётся частица |
| `particleSize` | `2` | Диаметр частицы в пикселях |
| `mouseRadius` | `100` | Радиус влияния курсора |
| `mouseForce` | `22` | Сила отталкивания от курсора |
| `ease` | `0.09` | Жёсткость пружины возврата |
| `friction` | `0.84` | Затухание скорости |
| `color` | `#ffffff` | Цвет частиц |

Плотность частиц и размер шрифта пересчитываются при изменении размера окна (с дебаунсом 150 мс) и после загрузки веб-шрифтов. При `prefers-reduced-motion: reduce` canvas скрывается, а вместо него показывается обычный текст заголовка.

## Стили

Все дизайн-токены заданы в `:root` в начале `css/style.css`.

```css
--color-black: #000;
--color-white: #fff;
--color-muted: #666;
--color-dark: #22263a;
--color-accent: #8d2f1d;
--font-display: "Bergamasco", "Times New Roman", serif;
--font-text: "Golos Text", "Segoe UI", sans-serif;
--font-condensed: "Roboto Condensed", "Arial Narrow", sans-serif;
--page-width: 1440px;
--container: 1312px;
--pad: 64px;
--gap: 24px;
--radius-pill: 100px;
```

Страница ограничена шириной 1440px и центрируется. Адаптив построен на трёх контрольных точках:

- **1200px** — уменьшаются боковые отступы, перестраиваются блоки афиши и автора;
- **900px** — включается бургер-меню, все многоколоночные сетки становятся одноколоночными;
- **600px** — карточки и кнопки переходят в вертикальный layout, уменьшаются медиа-блоки.

## Доступность

- Текст hero-заголовка продублирован в разметке и доступен скринридерам, canvas помечен `aria-hidden="true"`.
- У кнопок карусели и бургера есть `aria-label`.
- Поддержан режим `prefers-reduced-motion`: отключаются вращение звёзд и анимация частиц.
- Изображения имеют `alt`, декоративные элементы — пустой `alt` и `aria-hidden`.
